# Phonics Quest

A fun phonics game for early readers: sight words, digraph lessons, picture quests,
daily levels, and a dress-up avatar earned with points.

Open `index.html` in Chrome or Edge, or visit the GitHub Pages address for this repo.

Progress is saved in the browser. Use the Grown-up corner (default PIN 1234, change it
in `index.html`) to save a backup file.
